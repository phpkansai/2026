# 画像スロット

このフォルダに **決まったファイル名** で画像を置くと、再ビルド後に自動で表示されます。
拡張子は svg / png / webp / jpg / jpeg / gif のいずれか（svg → png → … の順に探します）。
無い場合は仮の図形やグレーの枠が表示されます。

| ファイル名 | 使われる場所 | 推奨 |
|---|---|---|
| `logo-header.*` | ヘッダー左のロゴ | 横長、高さ36px表示（SVG推奨） |
| `hero-logo.*` | ヒーローのロゴ一式（マスコット＋タイトル文字が1枚になったもの）。**これがあれば下2つは不要** | 幅600px表示（SVG推奨） |
| `hero-mascot.*` | ヒーロー上部のマスコット（hero-logo が無い場合） | 透過PNG or SVG |
| `hero-title.*` | ヒーローのタイトルロゴ（hero-logo が無い場合） | 横長、幅560px表示（SVG推奨） |
| `hero-date.*` | ヒーローの日付・会場（白い角丸背景込み）。無ければテキスト表示 | 横長、幅500px表示（SVG推奨） |
| `cloud.*` | 雲の装飾（各所で使い回し） | 透過PNG or SVG |
| `skyline.*` | フッター上の京都の街並みシルエット | 横長（1200px以上）、紫 #8568CD |
| `footer-mascot.*` | フッターのマスコット（無ければ hero-mascot を流用） | 正方形 |
| `ogp.*` | OGP画像（SNSシェア時） | 1200×630 px |
| `favicon.*` | ファビコン | 正方形 SVG or PNG |

スポンサーロゴは `src/assets/sponsors/`、スタッフ写真（fortee未登録者のみ）は `src/assets/staff/` に置きます。
