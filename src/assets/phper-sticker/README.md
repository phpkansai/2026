# PHPerシール説明ページの画像

`/phper-sticker/` ページに載せる Peatix の画面例です。**決まったファイル名**で置くと自動で表示されます
（拡張子は png / jpg / webp のいずれか。無い場合は本番では何も出ず、開発サーバーではグレーの枠が出ます）。

| ファイル名 | 内容 | 元画像の目安 |
|---|---|---|
| `ticket-number.*` | チケット番号の例（アプリ版のチケット画面。赤枠の「#1」） | 縦長 605×800 |
| `ng-1.*` | NG例1（お誘いチケットが「2 x」、「#1 #2」が一緒に表示されている） | 横長 800×127 |
| `ng-2.*` | NG例2（「#1」「#2」が別の行に表示されている。譲渡途中） | 横長 800×229 |

元画像は Google ドキュメント「PHPerシールの画像投稿のお願い note記事原稿」にあります。
取り出し方：ドキュメントで「ファイル → ダウンロード → ウェブページ（.html、zip）」を選ぶと、
zip の中の `images/` フォルダに `image1.png` … として入っています（番号は登場順。jpg でも可）。
NG例1（「2 x」「#1 #2」）と NG例2（#1 と #2 が別行）は似ているので、取り違えに注意してください。
